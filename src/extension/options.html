Dice Bridge

Rolls selected on any page are handed to the Dice Bridge receiver extension inside your Owlbear Rodeo room, which asks Rumble! to perform them.

Receiver setup

  1. Host dist/companion over HTTPS with CORS enabled (any static host works).
  2. In Owlbear Rodeo, add the extension by its manifest URL: https://your-host/manifest.json.
  3. Install Rumble! in the same room — the receiver writes Rumble's documented dice metadata.
  4. Enter the host's origin above and save.
